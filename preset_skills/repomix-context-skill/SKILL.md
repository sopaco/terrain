# Repomix Context Skill

MindMesh stores **agent-friendly** project context under `projects/{slug}/agent/repomix.md`, generated by [repomix-core](https://github.com/sopaco/repomix-rs).

## When to use

- Broad codebase questions: module layout, entry points, cross-file references
- Before multi-file edits: locate symbols and file paths quickly
- When structured docs (`human/`, `interfaces/`) are insufficient

## Query strategy

1. **Read meta first** — `agent/meta.json` has `total_files`, `total_tokens`, `top_files_by_tokens`
2. **Grep the pack** — search `repomix.md` for class names, routes, function names
3. **Read slices** — load only matching sections; avoid dumping the full pack into context
4. **Fall back to repo** — delegate file edits to OpenCode when the pack is stale

## Tools (MindMesh)

| Tool | Purpose |
|------|---------|
| `read_agent_pack` | Load pack header + metrics |
| `grep_agent_pack` | Regex search with optional context lines |
| `read_doc` | Human Litho docs under `human/` |

## Refresh

Re-run `mind-mesh assets pack-agent` after large refactors or when `meta.json.synced_at` is older than last merge.
