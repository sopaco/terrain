# 系统边界接口文档

本文档描述 MindMesh 的外部调用接口，包括 CLI 命令、配置参数和其他边界机制。

---

## 命令行接口（CLI）

MindMesh 提供 `mind-mesh` 命令行工具，使用 clap 库解析参数，包含 6 个一级命令组。

### `mind-mesh list`——列出已索引的项目

**描述**：列出所有已在 registry 中注册的 MindMesh 项目及其基本信息。

**参数**：无特殊参数（支持全局 `--repo-path`）

**使用示例**：
```bash
mind-mesh list
```

### `mind-mesh scan`——扫描 Git 仓库

**描述**：扫描一个 Git 仓库，检测技术栈，生成项目索引文档到 `.mind-mesh/` 中。

**参数**：
| 参数 | 类型 | 是否必须 | 默认值 | 说明 |
|------|------|---------|-------|------|
| `repo_path` | String | 否 | 当前 Git workspace | 要扫描的仓库路径 |
| `--slug` | String | 否 | 自动从路径生成 | 项目别名，用于知识目录路径 |

**使用示例**：
```bash
mind-mesh scan /path/to/repo --slug my-project
```

### `mind-mesh search <query>`——全文搜索知识库

**描述**：在所有已索引的知识文档中执行全文搜索。

**参数**：
| 参数 | 类型 | 是否必须 | 默认值 | 说明 |
|------|------|---------|-------|------|
| `query` | String | 是 | - | 搜索关键词 |
| `--project` | String | 否 | 当前 workspace 项目 | 限制搜索范围到指定项目 |
| `--limit` | Number | 否 | 20 | 最大结果数 |

**使用示例**：
```bash
mind-mesh search "LLM provider" --project mind-mesh
```

### `mind-mesh assets`——知识资产生成管理

| 子命令 | 描述 | 关键参数 |
|-------|------|---------|
| `pack-agent <repo_path>` | Repomix 源码打包 | `--slug` |
| `plan-litho <repo_path>` | 预览 Litho 生成计划 | `--slug` |
| `run-litho <repo_path>` | 运行 Litho 文档生成 | `--slug` |
| `agent-context <repo_path>` | 生成 Agent 上下文 | `--slug`, `--force` |
| `register <repo_path>` | 注册项目到 registry | `--slug` |
| `list-human --project <slug>` | 列出项目的人类文档 | - |
| `plan <repo_path>` | 完整资产生成计划 | `--slug` |

**使用示例**：
```bash
mind-mesh assets register /path/to/repo --slug my-project
mind-mesh assets pack-agent /path/to/repo --slug my-project
mind-mesh assets run-litho /path/to/repo --slug my-project
```

### `mind-mesh tools`——ACP 模式工具集（为 AI 编码助手设计）

**描述**：所有输出为 JSON 格式，专为 AI 编码助手的工具调用场景设计。

| 子命令 | 描述 | 关键参数 |
|-------|------|---------|
| `list-projects` | 列出项目 | 无 |
| `pack-meta --project <slug>` | 获取 repomix 元数据 | - |
| `grep-pack --project <slug> --pattern <pat>` | grep 搜索 repomix | `--context`, `--limit` |
| `read-pack-file --project <slug> --file <path>` | 读取源码片段 | `--start-line`, `--end-line` |
| `read-context --project <slug>` | 读取 Agent 上下文 | `--section`（可选） |
| `search --query <q>` | 全文搜索知识文档 | `--project`, `--limit` |
| `read-doc --project <slug> --path <rel_path>` | 读取知识文档 | - |

**使用示例**：
```bash
mind-mesh tools search --query "architecture" --project mind-mesh --limit 5
mind-mesh tools grep-pack --project mind-mesh --pattern "fn main"
mind-mesh tools read-context --project mind-mesh --section "core-modules"
```

### `mind-mesh env`——AI 工程环境管理

| 子命令 | 描述 |
|-------|------|
| `status` | 显示当前仓库的环境集成状态 |
| `plan` | 预览集成计划 |
| `apply` | 执行环境集成 |

## 环境变量接口

| 环境变量 | 类型 | 默认值 | 含义解读 |
|---------|------|-------|---------|
| `MIND_MESH_REPO_PATH` | 路径 | - | 指定工作仓库路径——CLI 和桌面应用都支持，设置后无需每次手动传入 repo_path |
| `MIND_MESH_LITHO_SKILL` | 路径 | `preset_skills/litho-documents-skill/` | 自定义 Litho skill 目录——如果你修改了默认 skill，用这个变量指向新位置 |
| `MIND_MESH_LITHO_WORKSPACE` | 路径 | `.mind-mesh/.litho-agent/` | Litho 研究中间产物的存放位置——调试时可以直接查看 Agent 的研究过程 |
| `MIND_MESH_HUMAN_OUTPUT_DIR` | 路径 | `.mind-mesh/human/` | 最终人类文档的输出目录——文档都写在这里 |
| `MIND_MESH_ACP_BINARY` | 字符串 | `opencode` | ACP 代理的二进制文件名——如果你用其他兼容 ACP 的工具，改这个 |
| `MIND_MESH_ACP_ARGS` | 字符串 | `--non-interactive` | ACP 代理的参数——默认非交互模式，适合自动化场景 |
| `MIND_MESH_ACP_COMMAND` | 字符串 | - | 完全自定义 ACP 启动命令——覆盖 binary+args 组合，适合复杂启动场景 |
| `MIND_MESH_LITHO_TIMEOUT_SECS` | 数字 | 2700 | Litho 生成超时时间（秒）——45 分钟对于大型项目可调高 |

## LLM 模型配置

模型配置可以通过设置文件或环境变量管理。以下是支持的 Provider 和对应的环境变量：

| Provider | 环境变量 | 说明 |
|---------|---------|------|
| OpenAI | `OPENAI_API_KEY` | 云端 LLM，需要 API Key |
| OpenAI | `OPENAI_BASE_URL` | 可自定义 API 端点（兼容 OpenAI 格式的代理服务） |
| Ollama | `OLLAMA_BASE_URL` | 本地 LLM，默认 `http://localhost:11434` |
| Ollama | `OLLAMA_MODEL` | 使用的模型名（如 `llama3`） |
| LM Studio | `LMSTUDIO_BASE_URL` | 本地 LLM，默认 `http://localhost:1234` |
| LM Studio | `LMSTUDIO_MODEL` | 模型名（可选） |

**示例配置**（通过设置文件）：
```json
{
  "provider": "openai",
  "model": "gpt-4o",
  "base_url": "https://api.openai.com/v1",
  "max_tokens": 4096,
  "temperature": 0.0
}
```

## 集成建议

**CI/CD 集成**：在 CI 环境中可以使用以下命令序列自动化知识资产生成：
```bash
# 1. 注册项目
mind-mesh assets register /path/to/repo --slug my-project

# 2. 打包 Agent 资产
mind-mesh assets pack-agent /path/to/repo --slug my-project

# 3. 生成 Agent 上下文（需配置 LLM）
mind-mesh assets agent-context /path/to/repo --slug my-project

# 4. 生成人类文档（需安装 OpenCode）
mind-mesh assets run-litho /path/to/repo --slug my-project
```

**AI 编码助手集成**：AI 助手通过 `mind-mesh tools` 命令组查询知识。例如，在 OpenCode 的 Ask 模式下，MindMesh skill 会自动调用 `list-projects`、`search`、`grep-pack`、`read-context` 等工具来回答关于项目架构的问题。
