### 建立的动效基础设施（后续改动应复用，勿另造轮子）

`src/app.css`：
- `@theme` motion tokens：`--ease-tr-out` (0.23,1,0.32,1)、`--ease-tr-in-out` (0.77,0,0.175,1)、`--ease-tr-drawer` (0.32,0.72,0,1)。`.mm-overlay-*` 已改用 token。
- `.tr-press`：按压反馈（:active scale(0.97)，160ms ease-out）。transition-property 显式包含 transform+colors+opacity+box-shadow —— 因为未分层 CSS 会赢过 Tailwind 的 `transition-colors`，合并属性表才能两者共存。reduced-motion 下只去掉 transform，保留颜色过渡。
- `.tr-pop`：下拉菜单 origin-aware 弹入（scale 0.96+fade，150ms），用 `--tr-pop-origin` 内联变量指定锚点（top left / top right）。
- `.tr-toast-in` / `.tr-toast-top-in`：通知类入场（240/180ms）。
- reduced-motion 的 overlay 处理从 `0.01ms !important` 一刀切改为 opacity 150ms 交叉淡化（gentler, not zero）。

`src/lib/overlayMotion.ts`：`schedulePresent` 去掉 reduced-motion 短路，统一 rAF 后翻 class（让 reduced 模式的 opacity 淡入真正生效）。

### 应用模式

- 离散按钮（CTA、图标按钮、tab）→ 加 `tr-press`（同时替代/合并 transition-colors）
- 菜单/列表行 → 只保留 `transition-colors`，不加 scale
- 下拉菜单容器 → `tr-pop` + `style="--tr-pop-origin: top left|right"`
- 进度条 → `transform: scaleX()` + `origin-left`，勿动画 width
- 避免 `transition-all`，用 `transition-[color,background-color,border-color,transform]` 显式列表

### 明确拒绝的动效（克制原则）

主导航 tab 切换动画、AskBar 输入 focus 动画、聊天消息 stagger、搜索结果列表入场 —— 高频或功能性阅读内容，不动。
