# 系统边界接口文档

本文档描述 Terrain 对外暴露的所有接口——CLI 命令、Tauri IPC、ACP JSON 工具、配置参数和环境变量。理解这些边界，是集成 Terrain 到 CI 流水线或外部 AI Agent 的第一步。

---

## 命令行接口 (CLI)

CLI 入口为 `crates/terrain-cli/src/main.rs`，命令定义在 `crates/terrain-cli/src/cli.rs:5-60`。所有命令共享全局参数 `--repo-path`，默认解析为当前 Git 工作区或环境变量 `TERRAIN_REPO_PATH`。

### `terrain list`

**描述**：列出 `~/.terrain/registry.json` 中所有已注册且已索引的项目。

**使用示例**：
```bash
terrain list
```

### `terrain scan`

**描述**：扫描本地 Git 仓库，建立 `.terrain/` 知识索引。触发 Git 元数据采集、OpenAPI 导入和 repomix 打包。

| 参数 | 类型 | 必须 | 默认值 | 含义解读 |
|------|------|------|-------|---------|
| `repo_path` | 路径 | 否 | 当前 Git 工作区 | 要扫描的仓库根目录 |
| `--slug` | 字符串 | 否 | 从目录名派生 | 项目在注册表中的唯一标识，影响 `.terrain/` 子目录命名 |

**使用示例**：
```bash
terrain scan /path/to/my-app --slug my-app
```

### `terrain search`

**描述**：对知识库进行全文搜索，覆盖 `human/` 和 `agent/` 下的 Markdown 文档。

| 参数 | 类型 | 必须 | 默认值 | 含义解读 |
|------|------|------|-------|---------|
| `query` | 字符串 | 是 | - | 搜索关键词 |
| `--project` | 字符串 | 否 | 全部项目 | 限定搜索范围到单个项目 |
| `--limit` | 数字 | 否 | 20 | 返回结果上限 |

### `terrain tools`（ACP JSON 工具）

**描述**：为外部 ACP Agent 提供的 JSON stdout 工具集，实现三层知识访问模型。这是外部 Agent 访问 Terrain 知识的**唯一推荐入口**——禁止直接读取活仓库源码。

#### `terrain tools list-projects`
列出所有已索引项目。

#### `terrain tools read-context`
| 参数 | 必须 | 含义解读 |
|------|------|---------|
| `--project` | 是 | 目标项目 slug |
| `--section` | 否 | context.md 中的章节标题（如「核心流程」）。省略则依赖 Macro 层预载 |

#### `terrain tools grep-pack`
| 参数 | 必须 | 含义解读 |
|------|------|---------|
| `--project` | 是 | 目标项目 |
| `--pattern` | 是 | 正则表达式，在 repomix 包中搜索 |
| `--context` | 否 | 匹配行上下文行数（默认 2） |
| `--limit` | 否 | 最大匹配数（默认 20） |

#### `terrain tools read-pack-file`
| 参数 | 必须 | 含义解读 |
|------|------|---------|
| `--project` | 是 | 目标项目 |
| `--file` | 是 | repomix 包内的文件路径 |
| `--start-line` / `--end-line` | 否 | 读取行范围，控制 token 消耗 |

#### `terrain tools freshness`
| 参数 | 必须 | 含义解读 |
|------|------|---------|
| `--project` | 是 | 目标项目。返回新鲜度评分；`score < 50` 时 Agent 应降权信任 |

**使用示例**：
```bash
terrain tools read-context --project terrain --section "核心流程"
terrain tools grep-pack --project terrain --pattern "ChatEngine" --limit 10
terrain tools freshness --project terrain
```

### `terrain assets`

**描述**：知识资产生成命令组，包括 Litho 文档生成、Agent 上下文生成、repomix 打包等。

### `terrain env`

**描述**：AI 工程环境集成——检测并安装 Skills、CodeGraph、RTK，写入 `AGENTS.md` 片段。

## Tauri IPC 接口（桌面应用）

桌面应用通过 `src-tauri/src/commands/` 下的 `#[tauri::command]` 函数暴露接口给 Svelte 前端。类型通过 `ts-rs` 从 Rust 单向导出到 `src/lib/generated/`。

| 命令模块 | 文件路径 | 主要职责 |
|---------|---------|---------|
| knowledge | `src-tauri/src/commands/knowledge.rs` | 项目列表、扫描、搜索、文档读取 |
| assets | `src-tauri/src/commands/assets.rs` | Litho/上下文/打包资产生成 |
| chat | `src-tauri/src/commands/chat.rs` | DeepWiki 问答（流式 SSE） |
| sdd | `src-tauri/src/commands/sdd.rs` | SDD 会话管理与阶段执行 |
| env | `src-tauri/src/commands/env.rs` | 环境集成计划与应用 |
| settings | `src-tauri/src/commands/settings.rs` | LLM/ACP 配置读写 |
| project | `src-tauri/src/commands/project.rs` | 项目概览、备注、初始化 |
| usage | `src-tauri/src/commands/usage.rs` | Token 用量监控 |

## 配置结构

### LLM 配置

存储在 `~/.terrain/settings.json`，由 `crates/terrain-agent/src/settings.rs` 管理。

| 配置项 | 类型 | 默认值 | 含义解读 |
|-------|------|-------|---------|
| `provider` | openai/ollama/lmstudio | openai | 用哪家 LLM 服务——决定 API 格式、定价和可用模型 |
| `api_key` | 字符串 | - | API 密钥，仅存本地 |
| `base_url` | 字符串 | provider 默认 | 自定义 API 端点（自托管或代理场景） |
| `model` | 字符串 | provider 默认 | 推理模型名称 |

### ACP 配置

| 配置项 | 类型 | 默认值 | 含义解读 |
|-------|------|-------|---------|
| `acp_binary` | 字符串 | `opencode` | ACP Agent 可执行文件路径，Litho 和 SDD CodeGen 依赖它 |
| `acp_args` | 字符串数组 | - | 启动参数（如 `--model`） |
| `agent_execution` | Acp/AcpNative/PureAcp | Acp | 执行模式：混合/纯 Native/纯 ACP |

### 环境变量

| 变量 | 含义解读 |
|------|---------|
| `TERRAIN_REPO_PATH` | 默认仓库路径，CLI 和工具在未指定 `--repo-path` 时使用 |
| `TERRAIN_ACP_BINARY` | 覆盖 ACP 可执行文件路径 |
| `TERRAIN_LITHO_TIMEOUT_SECS` | Litho 生成墙钟超时（默认 2700 秒 = 45 分钟） |
| `TERRAIN_LITHO_WORKSPACE` | Litho 研究中间产物目录 |
| `TERRAIN_HUMAN_OUTPUT_DIR` | 人类文档输出目录 |

## 集成建议

1. **CI 流水线**：在 merge 后执行 `terrain scan` + `terrain assets pack-agent`，将 `.terrain/` 变更提交回仓库
2. **外部 Agent 集成**：配置 ACP 模式，让 Agent 调用 `terrain tools` 而非 `grep`/`read` 活仓库
3. **新鲜度感知**：Agent 应答前先调用 `terrain tools freshness`，`score < 50` 时主动告知用户知识可能过期
4. **环境集成顺序**：按依赖顺序安装 `terrain-knowledge` → `repomix` → `codegraph` → `rtk`
