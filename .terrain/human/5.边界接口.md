# 系统边界接口文档

本文档描述 Terrain 系统的所有对外调用接口，包括 CLI 命令、Tauri IPC 命令、配置参数和环境变量。理解这些边界接口是集成 Terrain 到开发工作流或 CI/CD 流水线的第一步。

---

## 命令行接口 (CLI)

Terrain CLI 入口为 `terrain` 二进制（`crates/terrain-cli/src/main.rs`），使用 clap 定义命令树（`crates/terrain-cli/src/cli.rs`）。全局参数 `--repo-path` 指定仓库路径，默认从当前 Git 工作区或 `TERRAIN_REPO_PATH` 环境变量推断。

### 项目管理

#### `terrain list`
列出 `~/.terrain/registry.json` 中所有已注册项目。

#### `terrain scan [repo_path]`
扫描 Git 仓库建立 Markdown 知识索引。可选 `--slug` 指定项目标识。

```bash
terrain scan /path/to/repo --slug my-project
```

#### `terrain init [repo_path]`
完整项目初始化：扫描 + Litho 文档生成 + Agent 上下文生成。这是最常用的 onboarding 命令。

```bash
terrain init . --slug terrain
```

#### `terrain refresh [repo_path]`
快速刷新：扫描 + repomix 重打包 + 可选 context 更新，**跳过 Litho**。适合 CI 合并后增量更新。

### 知识检索

#### `terrain search <query>`
全文搜索知识库（human/ + knowledge/ + agent/）。

| 参数 | 类型 | 必须 | 默认值 | 含义解读 |
|------|------|------|-------|---------|
| query | String | 是 | — | 搜索关键词 |
| --project | String | 否 | 当前仓库 | 限定项目 slug |
| --limit | usize | 否 | 20 | 返回结果数上限 |

#### `terrain read <path>`
按相对路径读取 `.terrain/` 下的文档。

### DeepWiki 问答

#### `terrain ask query <query>`

| 参数 | 类型 | 必须 | 默认值 | 含义解读 |
|------|------|------|-------|---------|
| query | String | 是 | — | 自然语言问题 |
| --project | String | 否 | 当前仓库 | 目标项目 |
| --stream | flag | 否 | false | NDJSON 流式输出（chunk/tool_calls/phase/usage/done） |

```bash
terrain ask query "ChatEngine 如何路由到 ACP?" --stream
```

### SDD 工作流

#### `terrain sdd run --phase <phase>`

| 参数 | 类型 | 必须 | 含义解读 |
|------|------|------|---------|
| --project | String | 是 | 项目 slug |
| --phase | enum | 是 | Requirements / TechDesign / CodeGen / CodeReview |
| --session-id | String | 否 | 继续已有会话 |
| --input | String | 否 | 阶段输入（如需求描述） |

### ACP 工具（`terrain tools`）

外部 Coding Agent 通过 ACP 模式调用，输出 JSON 到 stdout。

| 子命令 | 描述 | 关键参数 |
|--------|------|---------|
| `list-projects` | 列出注册项目 | — |
| `pack-meta` | repomix 包元数据 | `--project` |
| `grep-pack` | 在 repomix 包中 grep | `--project --pattern --context --limit` |
| `read-pack-file` | 读取包内文件切片 | `--project --file --start-line --end-line` |
| `read-context` | 按 section 读取 context.md | `--project --section` |
| `search` | 搜索 human/knowledge 文档 | `--project --query` |
| `read-doc` | 读取指定文档 | `--project --path` |

### 环境集成

#### `terrain env plan` / `terrain env apply`
检测并安装 Skills、CLI 工具链和 AGENTS.md 片段。`plan` 预览变更，`apply` 执行安装。

### 设置管理

#### `terrain settings get` / `terrain settings set <file>`
读取或保存 LLM/ACP 配置（JSON 格式，匹配 `ModelSettings` schema）。

#### `terrain settings check-llm` / `terrain settings check-acp`
检测 LLM Provider 和 ACP Agent 连通性。

## Tauri IPC 接口

桌面应用通过 `invoke()` 调用 Rust 后端，类型定义在 `crates/terrain-core/src/ipc/` 并同步到 `src/lib/generated/`。前端封装在 `src/lib/api.ts`。

主要命令分组：

| 分组 | 命令示例 | 说明 |
|------|---------|------|
| 项目管理 | `initialize_project_cmd`, `get_project_overview_cmd` | 初始化、概览、备注 |
| 知识检索 | `search_knowledge`, `read_document` | 搜索与读取 |
| Litho | `plan_litho_cmd`, `run_litho_generation_cmd` | 计划与执行 |
| Ask | `ask_knowledge_cmd`, `create_ask_session_cmd` | 问答与会话 |
| SDD | `run_sdd_phase_cmd`, `create_sdd_session_cmd` | 工作流与会话 |
| 环境 | `plan_env_integration_cmd`, `run_env_integration_cmd` | 集成计划与执行 |
| 设置 | `get_model_settings`, `save_model_settings_cmd` | LLM/ACP 配置 |

完整列表见 `src-tauri/src/lib.rs:54-107`。

## 配置结构

### ModelSettings（`~/.terrain/settings.json`）

```json
{
  "provider": "openai",
  "profiles": {
    "efficient": { "model": "gpt-4o-mini", "base_url": "..." },
    "powerful": { "model": "gpt-4o", "base_url": "..." }
  },
  "acp": {
    "binary": "opencode",
    "args": [],
    "agent_execution": "acp_native",
    "ask_execution": "acp_only"
  }
}
```

| 配置项 | 类型 | 含义解读 |
|-------|------|---------|
| provider | enum | LLM 服务商（openai/ollama/lmstudio） |
| profiles.efficient | Profile | 日常推理模型，成本优先 |
| profiles.powerful | Profile | 复杂推理模型，质量优先 |
| acp.binary | String | ACP Agent 可执行文件路径 |
| acp.agent_execution | enum | AcpNative（混合）/ AcpOnly / NativeOnly |
| acp.ask_execution | enum | Ask 模式的执行策略 |

### 环境变量

| 变量 | 含义解读 |
|------|---------|
| `TERRAIN_REPO_PATH` | 默认仓库路径，CLI 全局 `--repo-path` 的 fallback |
| `TERRAIN_LITHO_TIMEOUT_SECS` | Litho 墙钟超时秒数，默认 2700（45 分钟） |
| `TERRAIN_LITHO_WORKSPACE` | Litho 研究中间产物目录 |
| `TERRAIN_HUMAN_OUTPUT_DIR` | Litho 最终人类文档输出目录 |
| `TERRAIN_LITHO_SKILL` | Litho 技能目录（只读） |
| `OPENAI_API_KEY` | OpenAI API 密钥（dotenv 加载） |

## 集成建议

**Cursor/OpenCode 集成**：在 ACP 配置中注册 `terrain tools` 作为知识检索工具集。Agent 应遵循三层检索顺序：Macro（read-context）→ Meso（search/read-doc）→ Micro（grep-pack → read-pack-file）。

**CI/CD 集成**：在 merge 后运行 `terrain refresh` 更新 repomix 包和新鲜度评分。完整文档更新用 `terrain init` 或 `terrain assets litho`。

**团队 onboarding**：新成员 clone 仓库后，若 `.terrain/` 已存在则直接阅读 `human/` 文档；否则运行 `terrain init` 生成完整知识资产。
