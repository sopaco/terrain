## 这个模块在做什么

项目初始化是 Terrain 的"入场流水线"——它把"一个裸仓库"变成"一个被 Terrain 管理的项目"。这条流水线执行一串精心编排的步骤：先扫描仓库结构，再打包 Agent 资产，接着生成人类文档（如 ACP 可用），最后生成 Agent 上下文。

它的设计核心是"自动化和优雅降级"：每个步骤都可以独立失败，失败后系统会生成提示信息而不是直接崩溃。例如，如果 ACP 代理不可用，系统会跳过文档生成但记下"请先配置 ACP 代理"的提示。

---

## 核心功能点

1. **仓库扫描**——`ProjectScanner::scan_repo()` 扫描目录结构，检测技术栈，生成 `project_index.md`。
2. **Agent 资产打包**——调用 `pack_agent_assets()` 用 repomix-core 打包源码。
3. **人类文档生成**——如果 ACP Agent 可用，调用 `run_litho_generation()` 生成 C4 文档。
4. **Agent 上下文生成**——在 Litho 文档生成后（如果有），调用 `run_agent_context_generation()` 刷新 Agent 上下文。
