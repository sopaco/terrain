# 文档引擎

**模块路径**：`crates/terrain-core/src/doc.rs` + `crates/terrain-core/src/human.rs`  
**生成日期**：2026-07-22

---

## 这个模块在做什么

文档引擎负责 Terrain 知识库中 Markdown 文档的读写、渲染和目录管理。它处理 `.terrain/human/` 下 Litho 生成的 C4 文档、`knowledge/` 下的领域术语表，以及 `agent/` 下的上下文文件。前端通过 `HumanDocTree.svelte` 展示文档树，`KnowledgeArticle.svelte` 渲染 Markdown 内容（含 Mermaid 图表）。

## 核心功能点

1. **文档读写**——`doc.rs` 提供 JSON/Markdown 文件的读写工具函数。
2. **人类文档管理**——`human.rs` 列出、读取和统计 `human/` 目录下的文档。
3. **Markdown 渲染**——前端 `MarkdownViewer.svelte` + `mermaidLoader.ts` 渲染文档和图表。
4. **文档树**——`list_human_docs_cmd` 返回 `HumanDocEntry` 列表供 UI 展示。
5. **目录统计**——`count_human_docs` / `count_markdown_in_dir` 统计文档数量。

## 关键组件

| 组件/类型 | 文件路径 | 核心职责 |
|---------|---------|---------|
| `read_json` / `write_json` | `doc.rs` | JSON 文件读写 |
| `list_human_docs` | `human.rs` | 列出人类文档 |
| `HumanDocEntry` | `schema.rs` | 文档条目结构 |
| `HumanDocTree.svelte` | `src/lib/components/` | 文档树 UI |
| `KnowledgeArticle.svelte` | `src/lib/components/` | 文档渲染 |
| `mermaidLoader.ts` | `src/lib/` | Mermaid 图表加载 |

## 与其他模块的交互

| 交互模块 | 方向 | 接口/协议 | 说明 |
|---------|------|---------|------|
| litho | 产出 | human/*.md | Litho 写入文档 |
| search | 消费 | Markdown 文件 | 搜索目标 |
| Tauri | 被调用 | `read_document`, `list_human_docs_cmd` | 桌面读取 |

## 实现亮点

Mermaid 图表通过 `mermaidLoader.ts` 懒加载渲染，支持 `MermaidLightbox.svelte` 全屏查看。
