# 数据库概览

---

## 本项目没有使用数据库

Terrain 的设计哲学是"知识随代码走"——所有数据都存储在**文件系统**中，而不是传统的关系型数据库或 NoSQL 数据库中。

**为什么不需要数据库？**

Terrain 存储的数据有两类：知识文档（Markdown 文件）和项目注册信息（JSON 文件）。对于知识文档来说，Markdown 是比数据库表更自然的存储方式——文档本身就需要人类可读、可版本控制、可跨平台访问。对于一个桌面工具来说，引入数据库意味着增加部署复杂度（用户需要安装和配置数据库服务），而这对于一个"帮助理解代码"的工具来说是不必要的。

**数据存储在哪里？**
- **知识资产**（文档、上下文、索引）：`{repo_path}/.terrain/` 目录下，以 Markdown + YAML frontmatter 格式存储
- **项目注册表**（已注册的项目列表）：`~/.terrain/registry.json`，一个简单的 JSON 文件
- **临时研究产物**（Litho 中间结果）：`.terrain/.litho-agent/` 目录

**这意味着什么？**
- 每个 Git 仓库自带完整的文档体系，知识随代码分支切换而自然流转
- 不需要安装、配置或维护任何数据库服务
- 所有数据都是纯文本，可以放在版本控制下（`.terrain/` 可以 `.gitignore` 或入库）
- 即使离线也能完整运行所有功能

> **置信度评分**：10/10 — 已全局搜索确认无 `.sql` 文件、无 migrations/ 目录、无 ORM 依赖、无数据库配置文件。
